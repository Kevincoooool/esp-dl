# 学生坐姿检测系统

本文档详细说明ESP32-P4上实现的学生坐姿检测功能，基于YOLO11人体姿态检测算法，能够实时分析学生的坐姿状态。

## 🎯 功能概述

系统能够检测以下坐姿状态：
- **正常坐姿** - 头部和肩膀角度正常，保持良好的坐姿
- **趴桌** - 头部位置过低，趴在桌子上
- **撑头** - 用手支撑头部的姿势
- **弯腰驼背** - 头部前倾，脊柱弯曲
- **后仰** - 身体过度后倾
- **未知状态** - 检测不到有效关键点或姿态异常

## 🔬 技术原理

### 关键点检测
基于COCO 17个关键点标准，重点分析以下部位：
```
关键点索引：
0:  nose (鼻子)          - 头部位置基准
5:  left_shoulder (左肩)  - 肩膀水平基准
6:  right_shoulder (右肩) - 肩膀水平基准  
9:  left_wrist (左腕)     - 撑头检测
10: right_wrist (右腕)    - 撑头检测
```

### 算法指标

#### 1. 头肩角度 (Head-Shoulder Angle)
- **计算方法**: 鼻子到肩膀中心点的连线与水平线夹角
- **正常范围**: 70° - 110°
- **用途**: 判断头部是否前倾或后仰

#### 2. 头部倾斜角度 (Head Tilt Angle)  
- **计算方法**: 两肩连线与垂直线的夹角
- **阈值**: > 25° 为异常倾斜
- **用途**: 检测头部左右倾斜

#### 3. 撑头检测 (Hand Support Detection)
- **计算方法**: 手腕到鼻子的距离
- **阈值**: < 50像素认为在撑头
- **用途**: 识别用手支撑头部的动作

### 坐姿判断逻辑

```c
坐姿判断优先级：
1. 撑头检测 -> 撑头状态
2. 头肩角度 < 40° -> 趴桌
3. 头肩角度 < 60° && 头部前倾 -> 驼背  
4. 头肩角度 > 135° -> 后仰
5. 头部倾斜 > 25° -> 驼背
6. 70° ≤ 头肩角度 ≤ 110° -> 正常坐姿
7. 其他情况 -> 未知状态
```

## ⚙️ 系统架构

### 任务设计
- **camera_task** (优先级5): RGB888图像采集，100fps
- **display_task** (优先级4): 屏幕显示更新，30fps  
- **detect_task** (优先级3): 姿态检测和坐姿分析，每5帧一次
- **ui_update_task** (优先级2): UI状态更新

### 数据流
```
摄像头 -> 图像缓冲区 -> 显示队列 -> 屏幕显示
               ↓
        检测队列 -> 姿态检测 -> 坐姿分析 -> 结果队列 -> UI更新
```

## 📈 性能指标

- **检测频率**: 每秒检测20次 (每5帧检测一次)
- **响应延迟**: < 200ms
- **内存使用**: 增加约8KB用于坐姿分析
- **准确率**: 在正常光照条件下 > 85%

## 🔧 调试与优化

### 日志输出
```c
ESP_LOGI(TAG, "坐姿分析: %s", posture_names[posture]);
ESP_LOGI(TAG, "头肩角度: %.1f°, 头部倾斜: %.1f°, 撑头: %s",

```

### 参数调优建议
1. **环境适配**: 根据摄像头高度和角度调整角度阈值
2. **个体差异**: 考虑不同身高学生的比例差异
3. **光照条件**: 确保充足的环境光照以提高检测精度
4. **距离设置**: 根据实际使用距离调整撑头检测阈值

## 📚 应用场景

### 教育监控
- **课堂监督**: 实时监控学生上课坐姿
- **健康提醒**: 长期不良坐姿自动提醒
- **数据统计**: 记录学生坐姿习惯数据

### 健康管理
- **姿态矫正**: 帮助培养良好坐姿习惯
- **脊椎保护**: 及时发现驼背等有害姿势
- **视力保护**: 防止趴桌等伤害视力的姿势
